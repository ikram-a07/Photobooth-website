PROJECT OVERVIEW:

I developed an interactive web application that that uses a user’s live webcam access and canvas rendering to generate a downloadable photobooth strip

The photobooth website simulates a physical photobooth, allowing the users to view a live feed, take up to 3 photos, which are then displayed on a 3 strip photobooth. The users are able to retake any of the photos and download this photo onto their respective device.

This project explores how dynamic software tools can be used to create personalised and fun tools for users.


FEATURES:

Live webcam preview: Displays the user’s camera feed in the application

Photo capture: Captures images from the live feed using JavaScript

Three-photo limit: Restricts each photobooth strip to three captured photos

Photo rewind; Removes the most recently captured photo, allowing the user to retake it

Photobooth strip generation: Places captured photos within a PNG photo frame

Image download: generates a downloadable image of the completed photobooth strip


TECHNOLOGIES USED:

JavaScript - handles camera access, photo capture, application logic and download and retake functionality

HTML - structures the application interface and interactive elements

CSS - styles the layout, buttons and visual design 

Figma - used to develop the initial visual design before implementation


KEY CONCEPTS:

Webcam access: Using the browser's MediaDevices API to request camera access through getUserMedia().

DOM manipulation and event handling: Selecting HTML elements and responding to user interactions with event listeners.

Canvas API and image rendering: Drawing captured video frames onto a canvas and combining images to generate the final photobooth strip.

State management and conditional logic: Tracking captured photos, enforcing the three-photo limit and controlling when users can capture or rewind photos.

Image export: Converting the completed canvas into a downloadable image.

Interface implementation: Translating a design created in Figma into a working web interface using HTML and CSS.
